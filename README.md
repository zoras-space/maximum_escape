# Maximum Productivity

A terminal-based escape room created for the **42 Berlin Game Jam 2026**.

**Theme: Max**

It is 03:42 at 42 Berlin.

You should have gone home hours ago.

Unfortunately, **Maximum Productivity Mode** has been enabled — and the building isn't letting you leave.

Explore your surroundings, inspect suspicious objects, collect what you need, and figure out how to escape.

## How to Play

The game is entirely text-based.

Read the descriptions and type commands to interact with the environment. Explore carefully — useful clues may be hidden in seemingly ordinary objects.

## Run the Game

Clone the repository:

```bash
git clone <REPOSITORY-URL>
cd <REPOSITORY-NAME>
```

Run:

```bash
python3 main.py
```

Requires **Python 3**.
